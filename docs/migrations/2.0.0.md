# Migrating to 2.0.0

2.0.0 removes the V1 coupon events, which 1.x dual-published beside V2.

| Removed | Use instead |
| --- | --- |
| `CouponPlacedV1`, `CouponLegV1`, `Topics.CouponPlaced` | `CouponPlacedV2` (`Legs`, `Bets`) on `Topics.CouponPlacedV2` |
| `CouponSettledV1`, `Topics.CouponSettled` | `CouponSettledV2` (`TotalStake`, `TargetPayout`, `Bets`) on `Topics.CouponSettledV2` |

- `CouponSettledV1.Stake` is `TotalStake`; `TargetPayout` is unchanged, so payout's delta logic carries over as is.
- `CouponSettledV1.EffectiveOdds` has no V2 field: derive `TargetPayout / TotalStake` when a display needs it.
- Every coupon since 1.0.0 was published as V2, so a consumer moving to V2 misses nothing; V2 topics keep their own retention.
- `swiftbets.wallet.v1` (gRPC) is unchanged and stays the wallet API.
